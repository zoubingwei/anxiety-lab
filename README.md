# 焦虑浓度检测 · Anxiety Lab

一个移动端优先的趣味测评网站。从 80 道题的题库里随机抽 25 题，测出焦虑浓度（0–100），并从 21 位历史与当代人物中匹配精神状态最像你的那一位。每次测的题都不一样。

纯静态站点：原生 HTML / CSS / JavaScript，零依赖、零构建、零后端，所有计算在浏览器本地完成。

## 运行

**方式一：直接双击**
打开 `index.html` 即可，无需服务器（已实测 file:// 协议下功能正常）。

**方式二：本地起服务（推荐，便于手机同局域网访问）**
```bash
cd anxiety-lab
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123/
```

**方式三：部署上线**
把整个 `anxiety-lab` 目录拖到以下任一平台即可，不需要任何构建配置：
- Cloudflare Pages / Netlify / Vercel（直接拖拽上传，或连 Git 仓库，输出目录填根目录）
- 任意静态托管、OSS / COS + CDN、GitHub Pages

## 怎么改内容

全部内容集中在 `assets/data.js`，改完刷新即可生效。

**加题目**：往 `QUESTIONS` 里加，四个维度保持题量相当（当前各 20 题）。每题必须属于一个维度 `dim`（A/B/C/D），`id` 不能重复（存档按 id 还原）。五个选项固定为 `OPTIONS` 里的 0–4 分。
```js
{ id: 81, dim: 'A', text: '题干……', note: '可选的小注释' }
```

**改题量**：只改 `TEST_META.total`。改成 20 就是每次抽 20 题，计分自动按 20 题归一化。建议别超过单维度题量的 4 倍。

**加名人**：往 `FIGURES` 里加一条，`tier` 必须是某个档位的 `key`。
```js
{
  id: 'dufu', tier: 'artist', name: '杜甫', mark: '杜',   // mark 必须单字
  era: '唐 · 安史之乱', role: '诗人', work: '《茅屋为秋风所破歌》',
  reason: '为什么像他，两句话，口语化',
  dimProfile: { A: 0.60, B: 0.70, C: 0.45, D: 0.80 }  // 四维相对强度 0–1
}
```

**调档位**：`TIERS` 的区间必须首尾相接覆盖 0–100（自检脚本会校验），每档建议 3 位名人。

**改建议文案**：每档的 `advice` 是三条 `{ tag, text }`，tag 是三段式的小标题（今天就能做 / 这周挑一件 / 长期来看），text 控制在 45 字以内，手机上三行内能读完。

**改维度解读**：`DIMENSIONS[].insight` 分 high（>=70）/ mid（40-69）/ low（<40）三档，配方条形图下面那一句就是从这里取的。

## 抽题与计分规则

**抽题**：`pickQuestions(25)` 先从四个维度各取 6 题，剩下 1 题从剩余题库里随机补，最后整体打乱顺序。所以每次的题目组合都不同，但四个维度一定都被覆盖（实测 3000 次，3000 组题全不重样，四维固定 6+6+6+7）。

**计分**：

1. 每题 0–4 分，25 题满分 100，直接就是焦虑浓度分数。
2. 四个维度分别按各自题数归一化算百分比，画成结果页的配方条形图——所以维度题数 6 或 7 不影响该维度的得分比例。
3. 按分数落到七个档位之一。
4. 在该档位的 3 位名人里算相似度：`100 - 82 × (四维 L1 距离 / 4)`，收敛到 72–97；排序时对用户最强维度额外加权 6 分，保证"最像"的那位真的对得上你的主要通道。

## 传播设计

- **分享图**：Canvas 手绘 750×1200 结果卡，不依赖任何截图库，长按即可保存。
- **分享链接**：结果页复制文案自带链接，带 `#s=分数&t=档位&f=名人` 参数；好友打开会在首页看到"你朋友测出 X 分 · 某档位"的提示条。
- **本地记忆**：上次结果连同抽到的题号一起存在 localStorage，回访时首页直接显示"查看上次结果"，点开能还原当初那一组题的结果。
- 无埋点、无第三方请求、不收集任何数据。

## 说明

测题参考焦虑自评量表常见的四个维度（躯体警觉、反刍思维、回避与控制、灾难化预期）设计，用于自我观察和娱乐，**不构成任何医学诊断**。高分档位的建议里给了就医提示，这是刻意保留的。

名人匹配只借用公开作品与经历中的性格气质做趣味比拟，不涉及对真实人物精神状况的判断。
